# Тренажёр аналитика

Офлайн-приложение для подготовки к собеседованиям на продуктового аналитика: метрики, маркетинг, статистика и A/B, SQL, Excel, продуктовые кейсы, кейсы из статей и план недели.

## Как опубликовать на GitHub Pages

1. На github.com нажми **New** (новый репозиторий), назови его, например, `analyst-trainer`, выбери **Public** и нажми **Create repository**.
2. На странице репозитория: **Add file → Upload files**. Перетащи всё содержимое папки `analyst-trainer` (не саму папку, а файлы и папки `data`, `icons` внутри неё). Нажми **Commit changes**.
3. **Settings → Pages**. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка — **/(root)**. Нажми **Save**.
4. Через 1–2 минуты сверху на той же странице появится адрес вида `https://<логин>.github.io/analyst-trainer/`.

## Как установить на телефон

- **iPhone (Safari):** открыть адрес → кнопка **Поделиться** → **На экран «Домой»** → **Добавить**.
- **Android (Chrome):** открыть адрес → меню **⋮** → **Установить приложение** (или **Добавить на главный экран**).

После первого открытия приложение работает без интернета. Когда интернет есть, оно само скачивает новые вопросы и план недели.

## Как обновлять

Всё содержимое — в папке `data/`, формат и правила описаны в `docs/CONTENT.md`.

- Claude присылает изменённые файлы (или архив целиком). Загрузи их поверх старых: **Add file → Upload files** → перетащи с сохранением папок → **Commit changes**.
- Прогресс не пропадёт: он хранится в телефоне и привязан к `id` вопросов.

## Как сообщать Claude о слабых местах

- В раунде кнопка **⚑** — заметка к вопросу: непонятный, спорный, хочу больше таких.
- **Прогресс → Отчёт для Claude → Скопировать** и вставить текст в чат.

## Где хранится прогресс

В памяти браузера на телефоне. Раз в неделю: **Прогресс → Сохранить копию прогресса**. Восстановить: **Загрузить копию**.
